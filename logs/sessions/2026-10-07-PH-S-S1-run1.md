## Open issues / honest limits
- Fidelity: the twin models the firmware's contracts, not the radio. Wi-Fi jitter, broadcast filtering on phone hotspots (D8) and real ADC noise are not modelled; real EMG artefact magnitude is unknown until bench (gain 45 raw_adc at intensity 150 is a guess).
- Real pulses self-end at <= 400 ms, so the watchdog can only be observed with a stuck-driver fault (`stick-a`). Documented.
- `emg_burst` is suppressed while a pulse+50 ms is active (twin-only convenience, per README); a flinch overlapping a stroke would not emit a burst event, but the envelope still shows it.
- `loss` drops inbound commands, outbound acks/stream/status; not discovery.
- Timing tests on the real-UDP layer use wide bands (Windows scheduling); core tests are exact. Ran 3x green; no flaky test seen.
- fake_haptic.py had uncommitted edits in the working tree before this run (git status); not mine, not touched.
- Node B default port is 8792+N in the twin (real nodes both use 8790 on different IPs). S2 must read ports from the discovery datagram `command_port` / the `ready` line, which the README already says.
