## B9 run rail - NOT DONE (not started, on purpose)
All six required items were done and verified first; B9 was optional ("only if time remains"). I did not start it rather than leave a half-built rail. Scoping notes for whoever takes it:
- The headset sends no step number, step count or phase length (X3), so the rail has to be derived: setup = calibrate + probe_pre; condition 1 / 2 = the n-th `induction` seen in this run (count it in `PhantomLiveModel`, reset where `inductionSeen` resets; do not trust `condition`, it is null in some phases); finale = dissolve / reveal / witness / done. Which condition is first comes from `conditionOrder`.
- "Next: Stone drop" is only safe when the next phase is certain. `self_touch`, `agency`, `dissolve`, `reveal` are config-dependent and not reported (D13: dissolve and reveal default ON), so a naive canonical order would sometimes name the wrong next phase. Either X3 (`game_state.step` / `steps_total`) lands first, or the label is limited to the certain steps (induction -> threat is certain only if agency is off).
- A per-phase progress bar needs the phase length: first `remaining_s` seen in a phase is within 0.5 s of it (status every 0.5 s).
- It changes the Status section on all 21 card + audience PNGs again (R3: 21).
