## Method decisions (SPEC QUESTIONS answered conservatively)
- baseline RMS = RMS of the raw envelope (incl. DC) in the 2 s before impact, excluded samples removed; peak = max
  envelope in the 1.5 s after; latency = first run >= 30 ms of samples > baseline mean + 3 SD (SD floor 1 % of mean, min 0.5), linearly interpolated.
- IMU: |a| - baseline mean, peak = max |dev| in window; latency with dev > 3 SD (SD floor 0.05 m/s2). Extra id `flinch_imu_latency_ms` (prompt asks for it; not in 03-SPEC list). IMU gets the same motor gating (same sleeve as the motors).
- Gating: [send, send+250] ms for every delivered haptic_cue (event t_ms = send) and every self_touch cue_send_ms; OR with file `motor_excl`. `emg_windows_excluded` = windows overlapping [impact-2000, impact+1500]. > 50 % of the response window excluded -> degraded; fully excluded/baseline < 10 samples -> missing.
- Wrist: `r_wrist`, existing 6 Hz zero-phase filter, speed > 0.15 m/s, threshold crossing interpolated; the filter makes latency accurate to ~ +-15 ms (72 Hz + 6 Hz low-pass), tested with that tolerance, not +-5.
- drift_change_cm = post - pre (both confirmed). Pre = probe with the same trial, else latest earlier pre (reason `shared_pre_probe`). Fixture witness numbers (2.4/0.4) are therefore not reproduced; the computed 2.0/0.0 follows the definition.
- stroke_timing_err_ms = |timing_err_ms| of stroke events; extra `async_delay_ms {mean,p95}` = cue_a_send - brush_pass_a.
- Step-like onsets sampled at 10 ms carry up to 10 ms error with interpolation; envelopes are ramps in practice.
- Quality values used: ok / degraded / missing (value null). Reasons: rate_hz_*_below_45, sensor_gap_*ms, motor_exclusion_*, node_absent_bio/haptic, probe_unconfirmed, no_flinch_detected, no_withdrawal_detected, ...
