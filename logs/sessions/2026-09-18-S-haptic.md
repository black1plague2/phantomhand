## CHECKPOINT 2: fake_haptic.py

Implemented `sim/haptic/fake_haptic.py`:
- `asyncio` UDP protocol (`asyncio.DatagramProtocol`) listening on `--port` (default 8790).
- Every inbound datagram schema-validated; invalid ones counted (`invalid_count`), never crash the loop.
- `cue` -> `ack` (ok=true), `ping` -> ... (see README). `stop`/`config` accepted, no reply (fire-and-forget per contract).
- `hello` broadcast every 1s on `--discovery-port` (default 8791): `{"opus_haptic":1,"device_id":...,"port":<port>,"fw":...}`.
- `status` at 1 Hz: device_id, slowly-draining battery_pct, motors_ok, imu_ok, fw, last_cue_id.
- `--imu`: emits `imu` at <=50Hz with fake seq/ax..gz.
- `--drop-after S`: after S seconds stop replying/broadcasting (simulates disconnect), datagrams still counted.
- `--battery-start`, `--json-log <path>` (one JSON line per received cue), live console log of cue/intensity/pattern/gap.
- `--selftest`: sends a `cue`, waits for `ack`, prints measured send->ack latency, exits. Used for the
  end-to-end verification requested (no separate scripted-sender file needed).
