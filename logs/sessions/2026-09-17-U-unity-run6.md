**Real bug found and fixed on first run:** `-executeMethod BatchDressOrchardScene` threw
`MissingComponentException: There is no 'SphereCollider' attached to the "fruit_apple" game object` from
`MakeFruitGrabbable` line `root.GetComponent<SphereCollider>() ?? root.AddComponent<SphereCollider>()`. Root
cause: the C# `??`/`?.` operators test the left operand against **raw CLR null** (IL `brtrue`), not Unity's
overloaded `==`/`!=` — a well-documented UnityEngine.Object gotcha. `GetComponent<T>()` returning "not found"
relies on that overload, so `??` can short-circuit and skip `AddComponent` in some engine-internal-null cases,
leaving a broken reference. Fixed all 5 occurrences (`SphereCollider`, `Rigidbody`, `OneGrabFreeTransformer`,
`Grabbable`, `HandGrabInteractable` in `MakeFruitGrabbable`; `BoxCollider` in `MakeBasketTrigger`) to explicit
`var x = root.GetComponent<T>(); if (x == null) x = root.AddComponent<T>();`.
