## Design notes / deviations
- VirtualArmRig hand is a PROCEDURAL joint hierarchy (palm ellipsoid + 3-segment fingers + 2-segment thumb), not a duplicated ISDK skinned hand: it needs no IHand driver, poses deterministically (`Curl` 0..1 for A5/agency) and is hash-testable. The asmdef still references Oculus.Interaction as the prompt asked, but nothing uses it yet. If Opus wants the ISDK skin, only `BuildHand` changes.
- BrushRig/ArmGeometry: the brush path is pure maths over (wrist, elbow direction, forearm length, motor positions) and never reads arm renderers, so A2 can set `arm.Alpha = 0` / `Visible = false` and the brush keeps stroking (test `Brush_KeepsStroking_WhenTheArmIsInvisible`). `arm.WorldPos(fromWristCm)` returns the dorsal surface point (A3 bands: `WorldPos(motor_a_from_wrist_cm)` and `+ motor_spacing_cm`). `arm.Alpha` swaps to transparent URP twins of the materials when < 1.
- Measured pass times: BrushRig samples its own animated distance each Tick and interpolates the crossing of the motor distances inside the frame (`OnPass(stroke, slot, ms)`). StrokeDriver pairs them with `HapticCueRecord.SentMs` (U1 note) and the module computes SYNC timing_err_ms = send + lead - measured pass.
- Threat: impact time = release session ms + fixed steps x fixedDeltaTime (StoneBody.FixedUpdate counts steps; tests count manually under Physics.Simulate) = physics time mapped onto the SessionClock. First collision with the `VirtualHandHit` compound proxy counts; hitting only the table gives ok:false after 2 s. Real-hand abort: real palm within 9 cm horizontally of the drop point -> Debug.Log "[PhantomHand] threat aborted: ..." and threat_impact ok:false, nothing falls. Telegraph starts 0.5 s after the Threat phase begins (`threatLeadInS`) so worst case (miss) 0.5+0.6+2+1.5 = 4.6 s fits the 5 s phase.
- ArmThreatPresenter API for U5: `Bind(module, haptic, nodeA, nodeB, clock, hands)`, `SetCalibration(wrist, forearmAxis)` (axis = elbow toward fingers; else falls back to the real wrist at induction start or the arm-rest outline), `Tick()` once per frame after haptic Pump and module.Tick. The presenter calls arm.PlaceFromCalibration at induction start and `Freeze()` unless follow_during_induction; the arm follows only in Calibrate/Agency. Display: SYNC/ASYNC at induction start, IDLE when the stroking phases end. Strokes are scheduled all at once at induction start (HapticClient queues them); `HapticClient.Enabled/MaxIntensity` are set from haptics_enabled/haptic_max_intensity there.
- SPEC QUESTION (none blocking). CROSS-TRACK NOTE for U5: ThreatDrop.OnImpact -> module.SubmitThreatImpact and the 1.5 s collector -> SubmitThreatResponse are wired inside ArmThreatPresenter; U5 only needs to pass the IHandSource (RPalm/RWrist joints, raw, DataVersion-gated) and the two SleeveSensorClients (either may be null).
